Introduction to Python
Definition
What is Python?
Python is a high-level, interpreted, general-purpose programming language created by Guido van Rossum in 1991. It emphasizes code readability and simplicity, using English-like syntax. Python supports multiple programming paradigms — procedural, object-oriented, and functional.

Key characteristics: dynamically typed, garbage-collected, and supported by a massive standard library.
ℹ️
Python is interpreted: Code runs line by line through the Python interpreter — no compilation step needed. This makes debugging faster and development interactive.

Variables
A variable is a named reference to a value stored in memory. In Python, variables are created when you assign a value — no explicit declaration is needed. Python is dynamically typed, meaning the type is inferred at runtime and can change.

float

str

bool

Strings
Definition
What is a String?
A string (str) is an ordered, immutable sequence of Unicode characters, enclosed in single '...' or double "..." quotes (or triple quotes for multiline). Strings support indexing, slicing, and a rich set of built-in methods.

Immutability means once a string is created, it cannot be modified in place — operations always return a new string.

Tuples
Definition
What is a Tuple?
A tuple is an ordered, immutable sequence — like a list that cannot be changed. Defined with parentheses (...). Because they're immutable, tuples are faster and memory-efficient, and can be used as dictionary keys.

Use tuples for data that should not change: coordinates, RGB colors, database rows, return values from functions.

List vs Tuple

Lists are mutable (changeable). Tuples are immutable (fixed). Tuples are ~30% faster to iterate.

When to use Tuples

Coordinates, constants, function returns, dictionary keys, data integrity.

print(len(colors))           # 3

# Unpacking
x, y = point
print(f"x={x}, y={y}")

print(f"Red={r}, Green={g}, Blue={b}")

# Swap using tuples (Pythonic!)

a, b = b, a
print(f"After swap: a={a}, b={b}")
▶ Output
10 20 3 x=10, y=20 Red=red, Green=green, Blue=blue After swap: a=10, b=5

Sets
Definition
What is a Set?
A set is an unordered, mutable collection of unique elements — duplicates are automatically removed. Defined with curly braces {...} or set(). Sets support fast membership testing and mathematical set operations.

Use sets when you need: uniqueness, fast lookups, or set algebra (union, intersection, difference).
sets_01.py — Core Operations
# Example 1: Set creation and basic operations
nums = {1, 2, 3, 2, 1, 4}     # duplicates removed
print(nums)                      # {1, 2, 3, 4}

nums.add(5)
nums.discard(3)   # safe remove (no error if missing)
print(nums)

# Membership — O(1) average time
print(2 in nums)      # True
print(10 in nums)     # False

# Remove duplicates from a list
words = ["hi", "hello", "hi", "bye", "hello"]
unique = list(set(words))
print("Unique:", unique)
▶ Output
{1, 2, 3, 4} {1, 2, 4, 5} True False Unique: ['bye', 'hello', 'hi']
sets_02.py — Set Algebra
# Example 2: Mathematical set operations
python_devs = {"Alice", "Bob", "Charlie"}
js_devs     = {"Bob", "Diana", "Charlie"}

# Union — all developers
print(python_devs | js_devs)

# Intersection — know both languages
print(python_devs & js_devs)

# Difference — only Python, not JS
print(python_devs - js_devs)

# Symmetric difference — exclusive members
print(python_devs ^ js_devs)

# Subset / Superset checks
backend = {"Alice", "Bob"}
print(backend.issubset(python_devs))   # True
▶ Output
{'Alice', 'Bob', 'Charlie', 'Diana'} {'Bob', 'Charlie'} {'Alice'} {'Alice', 'Diana'} True

Dictionaries
Definition
What is a Dictionary?
A dictionary (dict) is an ordered (Python 3.7+), mutable collection of key-value pairs. Defined with {key: value, ...}. Keys must be unique and immutable (strings, numbers, tuples). Values can be anything.

Dictionaries offer O(1) average lookup by key — perfect for configurations, mappings, JSON-like data, and caches.

student = {

    "courses": ["Math", "CS", "Physics"]
}

# Access
print(student["name"])             # Alice
print(student.get("major", "N/A"))  # N/A (safe access)

# Modify
student["age"] = 22                # update
student["major"] = "Computer Science"  # add new key
del student["gpa"]                 # delete key

# Iterate
for key, val in student.items():
    print(f"  {key}: {val}")

print("Keys:",   list(student.keys()))
print("Values:", list(student.values()))
▶ Output
Alice N/A name: Alice age: 22 courses: ['Math', 'CS', 'Physics'] major: Computer Science Keys: ['name', 'age', 'courses', 'major'] Values: ['Alice', 22, ['Math', 'CS', 'Physics'], 'Computer Science']

if / elif / else
Conditionals let your program make decisions. Python uses if, elif (else-if), and else blocks. Indentation (4 spaces) defines code blocks — no curly braces needed. Python also supports ternary expressions and match (Python 3.10+).

Functions
Definition
What is a Function?
A function is a named, reusable block of code defined with def. Functions accept parameters (inputs) and optionally return a value. Python supports default arguments, keyword arguments, *args/*kwargs, and first-class functions (passed as values).

Lambda functions are anonymous single-expression functions — great for simple operations and higher-order functions.
functions_01.py — Definitions & Arguments
# Example 1: Function features
def greet(name, greeting="Hello"):
    """Return a greeting string."""
    return f"{greeting}, {name}!"

print(greet("Alice"))               # default greeting
print(greet("Bob", "Hi"))           # custom greeting
print(greet(greeting="Hey", name="Carol"))  # keyword args

# *args — variable positional args
def total(*nums):
    return sum(nums)

print(total(1, 2, 3))        # 6
print(total(10, 20, 30, 40))  # 100

# **kwargs — variable keyword args
def profile(**info):
    for k, v in info.items():
        print(f"  {k}: {v}")

profile(name="Alice", age=25, city="NYC")

# Lambda
square = lambda x: x ** 2
print(square(7))   # 49

nums = [3, 1, 4, 1, 5, 9]
print(sorted(nums, key=lambda x: -x))  # descending
▶ Output
Hello, Alice! Hi, Bob! Hey, Carol! 6 100 name: Alice age: 25 city: NYC 49 [9, 5, 4, 3, 1, 1]
functions_02.py — Decorators & Closures
import time

# Example 2: Decorator — add timing to any function
def timer(func):
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        end = time.perf_counter()
        print(f"{func.__name__} took {(end-start)*1000:.2f}ms")
        return result
    return wrapper

@timer
def compute_sum(n):
    return sum(range(n))

print(compute_sum(1_000_000))

# Closure — function remembering outer scope
def counter():
    count = 0
    def increment():
        nonlocal count
        count += 1
        return count
    return increment

c = counter()
print(c(), c(), c())   # 1 2 3
▶ Output
compute_sum took 18.42ms 499999500000 1 2 3

Comprehensions
Definition
List, Dict & Set Comprehensions
Comprehensions are concise, readable ways to create lists, dicts, or sets from iterables — often replacing multi-line for loops in one line. They are generally faster than equivalent for loops because they're optimized at the C level.

Syntax: [expression for item in iterable if condition]
comprehensions_01.py — List & Set
# Example 1: List & Set comprehensions

# Squares of even numbers up to 20

print(even_squares)

# Flatten a 2D list
matrix = [[1,2,3], [4,5,6], [7,8,9]]
flat = [n for row in matrix for n in row]
print(flat)

# Set comprehension — unique first letters
words  = ["apple", "avocado", "banana", "blueberry", "cherry"]
firsts = {w[0] for w in words}
print(firsts)

# Generator expression — memory efficient
gen = (x**2 for x in range(10))
print(sum(gen))  # lazy evaluation
▶ Output
[4, 16, 36, 64, 100] [1, 2, 3, 4, 5, 6, 7, 8, 9] {'a', 'b', 'c'} 285

Exception Handling
Definition
try / except / finally
Exceptions are runtime errors. Python handles them with try/except blocks. The else clause runs if no exception occurs; finally always runs (cleanup). You can also raise custom exceptions using classes inheriting from Exception.
exceptions_01.py — try/except/finally
# Example 1: Handling multiple exception types
def safe_divide(a, b):
    try:
        result = a / b
    except ZeroDivisionError:
        return "Error: Cannot divide by zero"
    except TypeError as e:
        return f"Type Error: {e}"
    else:
        return f"Result: {result:.2f}"
    finally:
        print("— safe_divide called —")

print(safe_divide(10, 2))
print(safe_divide(10, 0))
print(safe_divide(10, "x"))
▶ Output
— safe_divide called — Result: 5.00 — safe_divide called — Error: Cannot divide by zero — safe_divide called — Type Error: unsupported operand type(s) for /: 'int' and 'str'
exceptions_02.py — Custom Exceptions
# Example 2: Custom exception class
class InsufficientFundsError(Exception):
    def __init__(self, amount, balance):
        super().__init__(f"Cannot withdraw ${amount}. Balance: ${balance}")
        self.amount  = amount
        self.balance = balance

def withdraw(balance, amount):
    if amount > balance:
        raise InsufficientFundsError(amount, balance)
    return balance - amount

try:
    new_balance = withdraw(100, 150)
except InsufficientFundsError as e:
    print(f"⚠ {e}")

print(withdraw(100, 40))  # success: 60
▶ Output
⚠ Cannot withdraw $150. Balance: $100 60

File I/O
Definition
Reading & Writing Files
Python's built-in open() function handles file I/O. The context manager (with statement) automatically closes files even if an error occurs — always prefer it. Common modes: 'r' (read), 'w' (write/overwrite), 'a' (append), 'b' (binary).
fileio_01.py — Read & Write Text
# Example 1: Writing and reading text files
data = ["Alice,92", "Bob,78", "Carol,88"]

# Write
with open("students.txt", "w") as f:
    for line in data:
        f.write(line + "\n")
print("Written successfully")

# Read all at once
with open("students.txt", "r") as f:
    content = f.read()
print(content)

# Read line by line
with open("students.txt") as f:
    for line in f:
        name, score = line.strip().split(",")
        print(f"{name}: {score}")
▶ Output
Written successfully Alice,92 Bob,78 Carol,88 Alice: 92 Bob: 78 Carol: 88

OOP Basics
Definition
Object-Oriented Programming
OOP organizes code around objects — instances of classes (blueprints). Core pillars: Encapsulation (bundling data + methods), Inheritance (child class extends parent), Polymorphism (same interface, different behavior), Abstraction (hiding complexity).

Special methods (__init__, __str__, __repr__, __len__) let you customize how objects behave with Python's built-in operations.
oop_01.py — Classes & Inheritance
# Example 1: Class definition, inheritance, polymorphism
class Animal:
    def __init__(self, name, sound):
        self.name  = name
        self.sound = sound

    def speak(self):
        return f"{self.name} says {self.sound}!"

    def __str__(self):
        return f"Animal({self.name})"

# Example 2: Encapsulation with @property
class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner    = owner
        self.__balance = balance   # private

    @property
    def balance(self):              # getter
        return self.__balance

    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount
            print(f"Deposited ${amount}. Balance: ${self.__balance}")

    def withdraw(self, amount):
        if amount > self.__balance:
            print("Insufficient funds!")
        else:
            self.__balance -= amount
            print(f"Withdrew ${amount}. Balance: ${self.__balance}")

    def __repr__(self):
        return f"BankAccount('{self.owner}', balance=${self.__balance})"

acc = BankAccount("Alice", 1000)
acc.deposit(500)
acc.withdraw(200)
acc.withdraw(2000)
print(acc)
print("Balance:", acc.balance)
▶ Output
Deposited $500. Balance: $1500 Withdrew $200. Balance: $1300 Insufficient funds! BankAccount('Alice', balance=$1300) Balance: 1300
